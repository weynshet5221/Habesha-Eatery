# Habesha Eatery

A responsive restaurant website for **Habesha Eatery**, designed to provide customers with information about the restaurant, explore the menu, contact the restaurant, and make table reservations.

## Features

* Responsive restaurant homepage
* Hero section with restaurant introduction
* About section
* Sample menu section
* Full menu page
* Restaurant contact information
* Opening hours
* Restaurant address and map
* Social media link
* Customer contact form
* Table reservation form
* Reservation confirmation using JavaScript

## Pages

### Home

The homepage includes:

* Hero section
* About section
* Sample menu
* Footer

### Menu

The menu page allows customers to view the restaurant's available menu items.

### Contact

The contact page provides:

* Restaurant opening hours
* Restaurant address
* Map
* Social media link
* Contact form for customers to send their name, email, and message

### Reservation

The reservation page provides a form for customers to submit their table reservation details.

After clicking the reservation button, JavaScript displays a confirmation message to the customer.

## Technologies Used

This project was developed as a frontend web development project to practice building a multi-page restaurant website using HTML, CSS, and JavaScript.

It demonstrates responsive web design, page structure, styling, forms, navigation, and basic JavaScript interaction.
